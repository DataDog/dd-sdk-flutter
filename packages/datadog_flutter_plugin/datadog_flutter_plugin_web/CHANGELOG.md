# Changelog

## 1.0.0-preview.1

### Features

- Initial release of `datadog_flutter_plugin_web`, providing the web platform implementation of the Datadog Flutter Plugin via Flutter's federated plugin architecture.
- Updates the underlying Datadog Browser SDK used for RUM on web to v7.
- Requires Dart 3.10 and Flutter 3.38 or later.
- Split out of `datadog_flutter_plugin` as a federated plugin package.
