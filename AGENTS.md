# Repository Instructions

## Commit messages

- Follow the [commit message guide](CONTRIBUTING.md#commit-messages).
- Before requesting review, ensure that the pull request contains at least one
  Conventional Commit that changes the relevant package.
- Validate that commit's subject before you create it.
- Do not amend, rebase, or force-push only to repair a commit subject.
- If the pull request has no Conventional Commit, add a new summary commit.
